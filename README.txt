ShotsByAnik — free static photography & videography portfolio

Preview locally:
1. Extract this ZIP.
2. Open index.html in a modern browser.

Included:
- Existing cinematic dark/gold design retained
- ShotsByAnik branding and tagline
- 10 portfolio photographs
- Portfolio category filters
- Two supplied MP4 video stories
- About and contact sections
- Instagram and email contact links
- Responsive layout for mobile and desktop

Publishing:
This is a static website and can be hosted on a free static hosting tier.
Upload the complete folder (not just index.html) so the assets and videos work.
A custom domain, private admin dashboard, comments, likes and database-backed uploads
are not included in this static version.
